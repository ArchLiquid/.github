# Security

Do not publish vulnerability details, proof-of-concept exploits, credentials,
or private user information in an issue or discussion.

Use GitHub's private vulnerability-reporting flow in the affected ArchLiquid
repository. If private reporting is unavailable, email
`hello@archliquid.com` with the affected module, impact, and reproduction steps.

Never send a seed phrase or private key. ArchLiquid team members will never ask
for one.
